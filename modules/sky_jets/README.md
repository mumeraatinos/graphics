# Part F - Jet Flying Across The Screen

This folder contains a separate C/C++ `graphics.h` program for Part F of the assignment:

> Modify the hello world Graphics Program to write a code for a jet flying across the screen.

## Hosted Output Page

[https://gl.applications.co.zw/parts/part-f.html](https://gl.applications.co.zw/parts/part-f.html)

## Screenshot

![Part F output](part_f_jet_output.png)

## What It Shows

- Animated jet travelling from left to right across the screen.
- Fresh cinematic sky style with gradient sunset color, parallax clouds, distant skyline, and runway perspective.
- Detailed jet body, wings, tail fins, cockpit shine, oval windows, panel lines, engine nozzle, animated afterburner, contrail, and moving shadow.
- Uses the WinBGIm `graphics.h` library with BGI calls such as `initwindow`, `line`, `bar`, `fillellipse`, `fillpoly`, `outtextxy`, and `writeimagefile`.
- Double-buffered rendering so the screen stays stable while the jet moves.
- Timer-based frame stepping instead of redrawing as fast as the loop can run.
- Keyboard controls for pausing, restarting, saving, and closing.

## Files

- `part_f_jet_graphics_h.cpp`: main C++ source file using `#include <graphics.h>`.
- `part_f_jet_output.bmp`: saved screenshot generated by the program.
- `part_f_jet_output.png`: web-friendly PNG version of the saved screenshot.
- `build.ps1`: PowerShell build script.

## Build

This part reuses the WinBGIm `graphics.h` files vendored in `../retro_bitmap/vendor/winbgim`.

Build from this folder:

```powershell
.\build.ps1
```

If PowerShell blocks local scripts on your machine, use:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

## Run

```powershell
.\part_f_jet_graphics_h.exe
```

To generate the output BMP automatically and close:

```powershell
.\part_f_jet_graphics_h.exe --save-and-exit
```

## Controls

- `P`: pause or continue the jet animation.
- `R`: restart the jet from the left side.
- `S`: save the current frame as `part_f_jet_output.bmp`.
- `Q` or `Esc`: close the program.
